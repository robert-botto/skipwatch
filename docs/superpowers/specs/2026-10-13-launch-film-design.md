# SkipWatch launch film: design

Status: approved by Robert on 2026-10-13. This document is the brief every film builder works from.

## Goal

A short launch film that makes a developer scrolling X or LinkedIn stop, understand SkipWatch in one viewing with the sound off, and believe it works. A muted cut of the same scenes sits at the top of the README.

Success means:

- A cold viewer can say what SkipWatch does after one muted viewing.
- Every word and terminal line on screen is true of the shipped product.
- The README cut loops cleanly and stays small enough for GitHub.

## Deliverables

| Deliverable | Spec |
|---|---|
| Master film | About 50 s, 1920x1080, 60 fps, H.264 MP4 with a synthesized score, mastered to about -16 LUFS and -2 dBTP |
| README cut | About 15 s, muted, seamless loop, built from the same scenes; MP4 for the README plus a GIF fallback under 3 MB |
| Poster frame | A PNG of the end card, for the social post thumbnail |

## Where it lives

A separate private repository, `robert-botto/skipwatch-launch-film`. The renders and the score are 30 to 50 MB and do not belong in the plugin repository. Only the final README cut, the GIF fallback and the poster are copied into `docs/` in this repository, through a normal PR.

## Toolchain

- HyperFrames (Apache-2.0), pinned to an exact version, renders HTML and GSAP scenes to video.
- The score and sound effects are generated by a seeded Python script (numpy, scipy, ffmpeg), so there is no licensed audio.
- Fonts: a monospace and a sans with open licenses (for example Geist and Geist Mono under OFL), with the license files committed.
- The method follows the public Disclosure Gate launch film example. Its repository has no license, so none of its code, scenes or assets are copied. Only the approach is reused.

## Beat sheet

Picture and sound share one clock. Times are approximate until the timing pass.

| Time | Beat | Picture | On-screen text | Sound |
|---|---|---|---|---|
| 0 to 3 s | Hook | A generic video player at `12:04 / 47:12`; the cursor scrubs back and forth | `where did he click?` | A low digital hum fades in |
| 3 to 7 s | Turn | A terminal types `/skipwatch https://youtube.com/watch?v=...` | `You don't have to watch it.` | Key clicks, the hum rises |
| 7 to 20 s | Upload (centerpiece) | Half-width katakana rain floods the frame, then resolves line by line into a skill's numbered steps | `Claude knows kung fu.` | Rain ticks build, then a resolve chord |
| 20 to 33 s | Proof | The real review screen. Highlights land on the step counts with `0 inferred`, on `Safety flags: none`, and on timestamps such as `[on-screen 20:37]` in the draft | `Every step quoted, with a timestamp.` then `Gaps flagged, never invented.` then `48-minute video, skill in under 10 minutes.` | Soft ticks on each highlight |
| 33 to 41 s | Installed | The prompt line answered `yes`, then `Installed to ~/.claude/skills/<name>. Try it: "<trigger>".`, then Claude answering a request with the skill | none, or one short line | A bass hit when the skill lands |
| 41 to 50 s | End card | The first-run banner wordmark in its rain, the tagline, the install commands and the repository link | `never send a human to watch a tutorial.` | A short tail, then silence |

The end card's install lines are exactly the README Quickstart:

```text
/plugin marketplace add robert-botto/skipwatch
/plugin install skipwatch@skipwatch
/skipwatch <video link>
```

## Look

- A black background with white text. The katakana rain uses only the banner's character set: half-width katakana, `･` and spaces. No green, matching the black-and-white banner.
- The wordmark is the first-run banner from `skills/skipwatch/references/first-run-banner.md`, used unchanged, hidden messages included.
- Terminal frames are plain and monospace, with no real product logos and no real usernames or hostnames. Paths use `~/`.
- The hook's video player is a generic invented player. It never shows a real creator's footage, face, channel or logo.
- Text is large enough to read on a phone. Every text beat gets a reading hold.

## Accuracy rules

Every terminal line comes from real SkipWatch output: the review screen from `skipwatch review` on a real example run, the prompt line from `review-screen.md`, and the install line from `run-review-install.md`. Retyping it by hand is not allowed.

The proof stat comes from a measured run: Greg Isenberg's 48-minute video produced its skill in 9.5 minutes (run 7 of the M6-D example runs). The film says "under 10 minutes" and nothing faster.

The film must never claim or imply:

- that it works on any video, or on every platform
- accuracy figures, or "100% accurate"
- that it is instant
- that skills install without review (`--yes` exists, but the film shows the review)
- any feature that does not ship in v0.1.0
- any endorsement by a creator whose video appears in a proof screen

Before the final render, a check compares every on-screen string against the code and docs, and lists each string with its source file.

## Proof screen choice

The default proof screen is the real review screen from the `jq-json-parsing` example, because it is high confidence with 22 steps. Its `Source:` line keeps the creator credit as SkipWatch prints it: that is attribution, not endorsement. If Robert prefers no third-party name on screen, the fallback is a SkipWatch-owned demo tutorial recorded for the film and run through the real pipeline.

## Build process

1. A timing sheet: the beat sheet above, turned into exact frame times and sound cues shared by picture and sound.
2. Scene builders in parallel, one per beat, each working from the timing sheet, the look rules and the accuracy rules. Animation is deterministic and seekable, so any frame renders on its own.
3. Two competing hooks are built for 0 to 3 s and judged on whether a scroller stops and understands. The winner is refined.
4. The score script is built against the same cue times.
5. A review loop runs before every candidate render:
   - `hyperframes check` with 0 errors
   - phone-size contact sheets
   - a cold-viewer reaction from an agent that has never seen SkipWatch
   - a frame-by-frame defect hunt
   - the accuracy check
6. Robert reviews the candidate film. Then the final render, the README cut and the poster are produced.

## Out of scope

- Voiceover.
- Vertical 9:16 or square cuts. These can be added later from the same scenes.
- Paid stock footage or music.

## Decisions

- Proof screen: the `jq-json-parsing` example's real review screen (Robert, 2026-10-13).
- The private `robert-botto/skipwatch-launch-film` repository is created by the orchestrator (approved by Robert, 2026-10-13).
